Here is the summary of the changes made to create the "Zone SB" functionality in the app:

### Changes Made:
1. **Created New Page Components:**
   - `src/app/zone-sb/page.tsx`: A standard Next.js page wrapper for the new Zone SB tool.
   - `src/app/zone-sb/page-content.tsx`: The main component logic and UI for the Zone SB page. This page allows a user to input "Zone" directly (like PER, VIC1) and calculate the freight rates bypassing normal suburb and postcode lookups.

2. **Updated the App Header Navigation:**
   - `src/components/AppHeader.tsx`: Added navigation links for "Zone SB" under the "Compare" menu for both the desktop and mobile dropdowns.

3. **Modified Freight Calculation Logic:**
   - `src/lib/freightCalculations.ts`: Updated the `getPeZone` function to respect an `isZoneDirect` flag on location objects. When true, it treats the inputted string directly as the zone rather than trying to look it up in the database.

4. **Updated App Permissions and Types:**
   - `src/lib/types.ts`: Added `'zone-sb'` to the `PageKey` type and `ALL_PAGES` constant. Updated the `DEFAULT_PAGE_PERMISSIONS` to grant access to the `admin` and `bdm` roles.
