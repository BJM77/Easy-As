# **App Name**: LedgerLight

## Core Features:

- Transaction Logging: Allow users to manually enter financial transactions, including date, amount, category, and description.
- Balance Calculation: Automatically calculate and display the current account balance based on logged transactions.
- Category Management: Enable users to create and manage custom categories for transactions.
- Intelligent Suggestion Tool: Suggest appropriate transaction categories based on the transaction description using a tool that employs generative AI.
- Reporting: Provide basic reporting functionality to summarize income and expenses over time.
- Data Storage: Utilize a SQL database for persistence.

## Style Guidelines:

- Primary color: Deep purple (#673AB7) to convey professionalism and trust.
- Background color: Light gray (#F0F2F5), a desaturated tint of the primary.
- Accent color: Blue (#3F51B5), a more saturated hue for highlighting key actions and elements.
- Body and headline font: 'PT Sans', sans-serif for clarity and readability.
- Use clean, minimalist icons to represent transaction categories.
- Design a simple, intuitive layout that prioritizes ease of use and quick access to key information.
- Incorporate subtle animations to provide feedback and enhance the user experience (e.g., when adding a new transaction).
